# Icon set

One set, drawn for this console. A 24 px grid, a 1.5 px stroke, round caps and
joins, and `currentColor` throughout, so an icon takes the colour and the size
of the text around it.

The style follows O-RAN architecture diagrams and the network stencils everyone
draws in draw.io: a box for a function, a rack for a server, a cloud for the
core, arcs for radiation. Nothing is traced from a vendor's stencil.

The sprite is `console/templates/components/sprite.html`, inlined into every
page rather than fetched: a strict Content-Security-Policy and
`<use href="file.svg#id">` is a fight browsers keep changing sides on, and
48 short symbols cost less than the request would.

`tests/unit/test_icons.py` checks the set both ways: every icon the console
names is drawn, and every symbol drawn is used somewhere. It also holds the
grid, the stroke and `currentColor` to the values above.

**Adding one:** draw the symbol, use it, and add a row here. The test fails
until all three are true.

## Vendor marks

Vendors get a wordmark rather than their logo: the short name in the console's
own type, on that vendor's series colour, so a mark, a chip and a plotted line
agree. `console/vendors.py` explains why, and how to swap in real logo files if
you have ones you are licensed to redistribute.
